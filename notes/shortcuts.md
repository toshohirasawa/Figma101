# Keyboard Shortcuts

Essential Figma keyboard shortcuts for faster workflow.

## Tools

| Shortcut | Action |
|----------|--------|
| `V` | Move tool (default) |
| `F` | Frame tool |
| `R` | Rectangle |
| `O` | Ellipse |
| `L` | Line |
| `T` | Text |
| `P` | Pen tool |
| `Shift + P` | Pencil tool |

## View

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + 0` | Zoom to fit |
| `Cmd/Ctrl + 1` | Zoom to 100% |
| `Cmd/Ctrl + 2` | Zoom to selection |
| `Space + Drag` | Pan |
| `Cmd/Ctrl + R` | Toggle rulers |

## Selection & Layers

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + A` | Select all |
| `Enter` | Select child |
| `Shift + Enter` | Select parent |
| `Tab` | Select next sibling |
| `Shift + Tab` | Select previous sibling |
| `Cmd/Ctrl + G` | Group selection |
| `Cmd/Ctrl + Shift + G` | Ungroup |

## Editing

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + D` | Duplicate |
| `Cmd/Ctrl + C` | Copy |
| `Cmd/Ctrl + V` | Paste |
| `Cmd/Ctrl + Shift + V` | Paste over selection |
| `Cmd/Ctrl + Alt + C` | Copy properties |
| `Cmd/Ctrl + Alt + V` | Paste properties |
| `Backspace/Delete` | Delete |

## Components

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + Alt + K` | Create component |
| `Cmd/Ctrl + Shift + K` | Detach instance |
| `Alt + Drag` | Create instance |

## Boolean Operations

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + Alt + U` | Union |
| `Cmd/Ctrl + Alt + S` | Subtract |
| `Cmd/Ctrl + Alt + I` | Intersect |
| `Cmd/Ctrl + Alt + X` | Exclude |

## Misc

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + /` | Quick actions |
| `Cmd/Ctrl + \` | Toggle UI |
| `Cmd/Ctrl + Shift + ?` | Keyboard shortcuts |
