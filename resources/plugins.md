# Helpful Figma Plugins

A list of useful plugins to enhance Figma workflow.

## Content & Text

- **Content Reel** - Quickly populate designs with realistic content
- **Lorem Ipsum** - Generate placeholder text
- **Unsplash** - Free high-quality photos

## Design Tools

- **Iconify** - Access thousands of icons
- **Auto Layout** - Advanced layout tools
- **Instance Finder** - Find and manage component instances
- **Remove BG** - Remove image backgrounds

## Collaboration

- **Stark** - Accessibility tools and contrast checker
- **Figmotion** - Animation timeline for Figma
- **Figma to Code** - Export designs to HTML/CSS

## Productivity

- **Rename It** - Batch rename layers
- **Clean Document** - Remove unused styles and components
- **Sort Layers** - Organize layers alphabetically

## Resources

Explore more plugins in the [Figma Community](https://www.figma.com/community/plugins).
