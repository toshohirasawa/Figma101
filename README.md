# Figma101

A structured repository for organizing notes, learning materials, and resources related to Figma design exercises.

## 📁 Repository Structure

```
Figma101/
├── notes/          # Learning notes and documentation
├── resources/      # Useful resources and reference materials
├── projects/       # Practical projects and exercises
├── examples/       # Example designs and components
└── templates/      # Templates for notes and projects
```

## 📚 How to Use This Repository

### Taking Notes

1. Use the [note template](templates/note-template.md) for consistency
2. Save notes in the `notes/` directory
3. Organize by category (Concepts, Shortcuts, Workflows, Tutorials)

### Managing Resources

1. Collect useful links, articles, and tutorials in `resources/`
2. Organize assets like icons, UI kits, and plugins
3. Keep a curated list of helpful Figma plugins and community resources

### Working on Projects

1. Create a new directory for each project in `projects/`
2. Use the [project template](templates/project-template.md)
3. Include screenshots, design files (or links), and lessons learned

### Saving Examples

1. Store reusable components and patterns in `examples/`
2. Include visual examples with descriptions
3. Categorize by type (Components, Layouts, Prototypes, Techniques)

## 🚀 Getting Started

1. Clone this repository
2. Start with the templates in the `templates/` directory
3. Create your first note or project
4. Build your Figma knowledge base over time

## 💡 Best Practices

- **Be Consistent**: Use the provided templates for notes and projects
- **Add Context**: Include dates, categories, and references
- **Visual Documentation**: Add screenshots and exports to illustrate concepts
- **Regular Updates**: Keep your learning materials current and organized
- **Cross-Reference**: Link related notes and resources together

## 📖 Learning Path

Suggested progression:

1. **Fundamentals**: Basic tools, layers, and properties
2. **Components**: Creating and managing components
3. **Auto Layout**: Responsive design principles
4. **Prototyping**: Interactions and animations
5. **Collaboration**: Team features and design systems
6. **Advanced**: Plugins, API, and advanced techniques
